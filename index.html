Privacy And Policy of SayaHadir 
            Privacy Policy

            Last updated: 29 January 2026

            SayaHadir is a mobile application that operates using a WebView, displaying and providing services from https://sayahadir.my.id/#/. We respect user privacy and are committed to protecting personal data in accordance with applicable laws and Google Play policies.

            1. Information We Collect

            We collect only the data that is necessary to provide the core functionality of the application.

            a. Account / Login Information

            - Username and password are provided during login
            - Used solely for authentication, account management and application usage purposes

            b. Location Data

            - Approximate or precise device location (FINE / COARSE)
            - Used only for location-based features within the application are covering such features as:
                * Attend
                * Koreksi Kehadiran
                * New Shift / Shift Baru
                * Daily Activity
                * Synchronize
            - Location data is not used for background tracking or advertising purposes

            c. Camera Access

            - Used only when users choose to take photos or capture images within the app in such features as:
                * Attend
                * Koreksi Kehadiran
                * New Shift / Shift Baru
                * Cuti / Leave
                * Lembur / Overtime
                * Perjalanan Bisnis / Business Trip
                * Daily Activity
                * Profile
            - Camera access is activated only through user interaction

            d. Media & Storage Access

            - Access to device media or storage is used only for file or image uploads in such features as:
                * Attend (Offline)
                * Koreksi Kehadiran (Upload file / Offline capture)
                * New Shift / Shift Baru (Upload file / Offline capture)
                * Cuti / Leave (Upload file)
                * Lembur / Overtime (Upload file)
                * Perjalanan Bisnis / Business Trip (Upload file)
                * Daily Activity (Upload file / Offline capture)
                * Profile (Upload file)
            - The application does not access files without explicit user action

            e. Technical Information

            - technical diagnostics and logs
            - Used for application stability, performance, and security

            2. How We Use Information

            We use collected information to:
            - Provide and operate application features
            - Authenticate users and manage accounts
            - Support location-based functionality
            - Enable file and media uploads
            - Maintain application security and prevent misuse
            - We do not sell, rent, or trade user personal data to third parties.

            3. WebView and JavaScript Bridge

            - This application uses a WebView with a JavaScript Bridge to enable communication between the Android application and the web content. 
              We use some JavaScript Bridges such as:
                * requestLocation
                    Used for fetching the current location latitude and longitude, 
                    and to separate of how between platform (web and android) are requesting location, 
                    for example the web is using navigator interface, meanwhile the android is using the fusedClient
                * onLogout
                    Used for post logging out action such as clearing the cache, history, form data, removed all cookies and reload 
            - The bridge is used strictly for required application functionality
            - It does not access data beyond user consent
            - All interactions occur within the application context

            4. File Uploads

            When users upload files:
            - Files are transmitted securely through the application server to the S3 object storage server
            - Files are used only for the purpose requested by the user
            - Uploaded files are not shared with third parties without user consent

            5. Data Security

            We implement reasonable technical and organizational measures to protect user data from:
            - Unauthorized access
            - Alteration
            - Disclosure
            - Destruction
            We also applied steps to secured user data, such as:
            - Encrypting while transit (HTTPS/TLS)
            - Encrypting data at the sensitive information such as STR, SIP, Certificate and Employment Contract Letter
            - Restrictions access to related data by categorized user based on role
            - Monitoring system and logging at the server (mostly SQL and warning error)

            6. Data Retention and Deletion

            - Data is retained only as long as necessary to fulfill its purpose
            - Users may request account or data deletion
            - Requests are processed in accordance with applicable legal requirements

            7. User Rights

            Users have the right to:
            - Access their personal data
            - Request correction or deletion
            - Withdraw consent for specific data usage
            Requests can be submitted through the contact information below by mentioned the username.

            8. Children’s Privacy

            This application is not intended for children under the age of 13. We do not knowingly collect personal data from children.
