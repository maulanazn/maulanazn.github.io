Privacy And Policy of SayaHadir 
        Terakhir diperbarui: 12 Desember 2025

        Kebijakan Privasi ini menjelaskan bagaimana aplikasi ("SayaHadir") mengumpulkan, menggunakan, memproses, 
        dan menyimpan data pribadi pengguna. Dengan menggunakan Aplikasi, anda menyetujui praktik yang dijelaskan dalam dokumen ini.

        ---

        1. Data yang Kami Kumpulkan dan Dibaca

        Aplikasi dapat mengumpulkan dan membaca data berikut berdasarkan pola kerja aplikasi, seperti berikut:

        - Halaman ("Home") membaca data seperti username, company, attendance at, in time, out time, photo in, photo out
        - Halaman ("Attend") mengumpulkan data dengan detail seperti berikut:
            * area
            * admin id
            * id employee, yaitu id karyawan / nomor karyawan
            * username
            * company
            * location in, berbentuk string dari gabungan latitude dan longitude yang diambil dari frontend (bukan backend)
            * location out, berbentuk string dari gabungan latitude dan longitude yang diambil dari frontend (bukan backend)
            * photo in, berbentuk string dari pemrosesan binary captured photo ke Object Storage Cloud (return string url)
            * photo out, berbentuk string dari pemrosesan binary captured photo ke Object Storage Cloud (return string url)
            * in time, format waktu 'HH:mm:ss'
            * out time, format waktu 'HH:mm:ss'
            * notes
            * status, antara PROCESSED atau NOT_PROCESSED
        - Halaman ("Feed") membaca data dengan detail seperti berikut:
            * photo, yaitu foto profil (bagian halaman Profile yang akan disebut nanti)
            * fullname, (bagian dari halaman Profile)
            * description
            * notesAt, waktu data feed terbuat (Unix Epoch Format)
        - Halaman ("List Attendance") membaca data dengan detail seperti berikut:
            * username
            * company
            * attendance at
            * in time
            * out time
            * location in, bentuk url ke google maps dengan memisahkan latitude dan longitude dari koma (',') dan diakses berdasarkan index array
            * location out, bentuk url ke google maps dengan memisahkan latitude dan longitude dari koma (',') dan diakses berdasarkan index array
            * photo in
            * photo out
        - Halaman ("Koreksi Kehadiran") dengan detail seperti berikut:
            * Baca data
                # membaca kolom username, company, photo in, notes, attendance at, in time, out time, location in, location out
            * Simpan data
                # mengumpulkan area, admin id, id employee, username, company, location in, location out, photo in, photo out, attendance at, in time, out time, notes, status
        - Halaman ("New Shift /  Shift Baru") adalah fitur yang diperuntukkan kepada satpam ataupun petugas keamanan yang punya shift di atas jam kerja, dan detail seperti berikut:
            * Baca data
                # membaca kolom username, company, photo in, notes, attendance at, in time, location in
            * Simpan data
                # mengumpulkan area, admin id, id employee, username, company, location in, photo in, attendance at, in time, notes, status
        - Halaman ("Cuti / Leave") dengan detail seperti berikut:
            * Baca data
                # membaca kolom username, attachment (foto / dokument), remark, time start (unix epoch), time end (unix epoch)
            * Simpan data
                # mengumpulkan area, admin id, id employee, username, company, type (0 = cuti), time start, time end, remark, attachment
            * Edit data
                # mengubah kolom time start, time end, remark, dan attachment, juga type (tidak bisa dirubah, sudah diatur per activity, 0 = cuti)
        - Halaman ("Lembur / Overtime") dengan detail seperti berikut:
            * Baca data
                # membaca kolom username, attachment (foto / dokument), remark, time start (unix epoch), time end (unix epoch)
            * Simpan data
                # mengumpulkan area, admin id, id employee, username, company, type (1 = lembur), time start, time end, remark, attachment
            * Edit data
                # mengubah kolom time start, time end, remark, dan attachment, juga type (tidak bisa dirubah, sudah diatur per activity, 1 = lembur)
        - Halaman ("Perjalanan Bisnis / Business Trip") dengan detail seperti berikut:
            * Baca data
                # membaca kolom username, attachment (foto / dokument), remark, time start (unix epoch), time end (unix epoch)
            * Simpan data
                # mengumpulkan area, admin id, id employee, username, company, type (2 = perjalanan bisnis), time start, time end, remark, attachment
            * Edit data
                # mengubah kolom time start, time end, remark, dan attachment, juga type (tidak bisa dirubah, sudah diatur per activity, 2 = perjalanan bisnis)
        - Halaman ("Daily Activity") dengan detail seperti berikut:
            * Baca data
                # membaca kolom username, photo (foto / dokument), task, time start (unix epoch), time end (unix epoch), latitude dan longitude (dalam bentuk google maps url seperti yang ada di fitur "List Attendance"), type (Jenis Kegiatan)
            * Simpan data
                # mengumpulkan area, admin id, id employee, username, company, task, time start, time end, latitude, longitude, type, photo, other
            * Edit data
                # mengubah kolom task, time start, time end, latitude, longitude, type, photo, other
        - Halaman ("Manual Entry") dengan detail seperti berikut:
            * Baca data
                # membaca kolom username, time start, time end, remark
            * Simpan data
                # mengumpulkan area, admin id, id employee, username, company, type (default = 0), time start, time end, remark
            * Edit data
                # mengubah kolom area, admin id, id employee, username, company, type (default = 0), time start, time end, remark
        - Halaman ("Profile") dengan detail seperti berikut:
            * Baca data
                # membaca kolom fullname, birth place, birth date, religion, marital status, gender, nationality, address, postal code, photo, dan 'secret identity' yang sudah didekripsi seperti str (nomor, gambar), sip (nomor, gambar), certificate (gambar), employment contract letter (gambar)
            * Edit data
                # mengubah kolom fullname, birth place, birth date, religion, marital status, gender, nationality, address, postal code, photo, dan 'secret identity' yang dienkripsi seperti str (nomor, gambar), sip (nomor, gambar), certificate (gambar), employment contract letter (gambar)
        - Halaman ("Login") dengan detail seperti berikut:
            * Baca data
                # membaca input username dan password, password yang ter-hash, juga mengembalikan token yang ter-encode dengan menyimpan informasi seperti username, role, nama, servletRequest.getServerName() dan area, masing-masing dipisah dengan spasi sehingga bisa di-split berdasarkan spasi untuk diambil informasinya tergantung kebutuhan aplikasi, seperti pengambilan data input username dan token ke table user sqlite untuk fungsional fitur offline
        - Halaman ("Synchronize") dengan detail seperti berikut:
            * Baca data
                # membaca semua data dari fitur Attendance, Correct Attendance, New Shift, Leave, Overtime, Business Trip, Daily Activity
            * Sinkronisasi data ke server
                # Melakukan pengiriman data dari fitur-fitur yang disebut di atas, dengan mengirim data-data / kolom-kolom sesuai pada bagian 'Simpan data' yang disebut pada setiap Halaman di atas
            * Hapus data
                # Melakukan penghapusan data dari row table pada database lokal sqlite yang dimiliki masing-masing device ketika memasang aplikasi, juga menghapus gambar yang terkait dari penyimpanan / database lokal tersebut
        
        Semua data dikumpulkan dan dibaca hanya jika diperlukan untuk menjalankan fungsi Aplikasi, termasuk 'secret identity' pada halaman profil maupun table profiles yang terdiri dari str, sip, certificate dan employment contract letter yang dienkripsi dan didekripsi secara mandiri di backend / VPS.

        2. Cara Kami Menggunakan Data

        Data yang dikumpulkan digunakan untuk:

        - Pemrosesan data untuk laporan internal perusahaan, seperti untuk:
            * Data rekam absen, cuti, lembur, perjalanan bisnis, daily activity, juga
            * data lokasi untuk validasi kehadiran karyawan (secara manual dari HR, karena untuk menjaga integritas lokasi maupun data user)
            * Deteksi jam presensi, apakah telat, tepat waktu atau bahkan 'early person' sebagai bahan pertimbangan dari internal perusahaan seperti untuk penggajian ataupun regulasi lainnya
        - Terkait token, yang terdapat data 'role' di dalamnya, termasuk juga sebagai cara kami menggunakan data, seperti berikut:
            * Pemisahan akses data berdasarkan role
            * Hanya role HRD yang dapat akses ke semua user yang mempunyai id 'admin id', company id ataupun division yang sama / terkait
            * Role Manager dapat melihat data user sesuai dengan data division yang sama

        Kami tidak menjual, menyewakan, atau membagikan data pengguna kepada pihak ketiga, lebih-lebih kepada pihak tidak dikenal untuk tujuan komersial ataupun lebih buruk, untuk tindakan kriminal.

        ---

        3. Pemrosesan dan Penyimpanan Data

        Aplikasi memproses dan menyimpan data melalui:

        - Server milik kami yang di-hosting pada infrastruktur cloud pihak ketiga.
        - Object storage cloud pihak ketiga, untuk penyimpanan file seperti foto dan dokumen.

        Semua transfer data dilakukan melalui koneksi terenkripsi (HTTPS/TLS).

        ---

        4. Berbagi Data kepada Pihak Ketiga

        Kami hanya membagikan data kepada pihak berikut:

        - Penyedia server cloud tempat aplikasi kami berjalan.
        - Penyedia penyimpanan cloud (object storage) untuk file.

        Pihak ketiga ini hanya memproses data sesuai instruksi kami dan mengikuti standar keamanan industri.

        Kami tidak membagikan data pengguna untuk iklan atau tujuan pihak ketiga lainnya.

        ---

        5. Keamanan Data

        Kami menerapkan langkah-langkah untuk melindungi data pengguna, termasuk:

        - Enkripsi saat transit (HTTPS/TLS)
        - Enkripsi data pada 'secret identity'
        - Pembatasan akses ke data
        - Sistem pemantauan dan logging pada server

        ---

        6. Hak Pengguna

        Pengguna memiliki hak untuk:

        - Mengakses data pribadi mereka.
        - Memperbarui atau mengoreksi data.
        - Meminta penghapusan data.
        - Menarik kembali persetujuan terkait pemrosesan data tertentu.

        Permintaan dapat diajukan melalui kontak yang tersedia pada section nomor 9

        ---

        7. Retensi Data

        Kami menyimpan data selama masih diperlukan untuk menjalankan fungsi Aplikasi. Jika pengguna berhenti menggunakan Aplikasi atau meminta penghapusan, data akan dihapus sesuai dengan regulasi kami.
